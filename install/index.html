Official app installation

Shaylana RMS

Add the restaurant management system to your phone's Home Screen for quick, app-like access.

Install on Android

Tap the button below and confirm the installation when your browser asks.

If the install prompt does not appear, open this page in Chrome, tap the browser menu (⋮), then choose Install app or Add to Home screen.

Install on iPhone

1Open this page in Safari (not an in-app browser).
2Tap the Share icon.
3Choose Add to Home Screen, then tap Add.

Install on your device

Open this link on your Android phone or iPhone to see the correct installation steps. On a computer, you can open the RMS directly.

Open Shaylana RMS Already installed? Go to the system

No App Store or Google Play download is required. Your device will ask you to confirm before adding the app. Your existing RMS login and data remain in the main system.
